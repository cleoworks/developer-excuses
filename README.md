One funny single-line excuse a developer gives when code breaks in production. The program writes that one line, exactly, to `/output/entry.txt`.

> It worked for a year because we had one user — today we got a second one, and they clicked at the same time.

108 characters, one line. The system was never actually tested by concurrency: it worked for a year because only one user ever used it.

## Run it

```sh
python3 main.py
```
